# Excel 短线选股输出规范

短选报告除 Markdown 外**强制**输出 Excel 工作簿（xlsx），文件名 `短线选股_YYYYMMDD.xlsx`，与 Markdown 同目录（`/var/minis/shared/股票/短线选股/`）。

## 工作簿结构

必须包含 **4 个 sheet**（顺序固定）：

### Sheet 1：精选

只保留通过二次筛选的 5-8 只标的，每只**必含详细备注列**。

| 列 | 列名 | 说明 |
|---|---|---|
| A | 代码 | 6 位 |
| B | 名称 | — |
| C | 申万一级 | 板块 |
| D | 评分 | 0-100 |
| E | 市值（亿） | 流通市值 |
| F | 现价 | — |
| G | 主策略 | 6 选 1 |
| H | 突破入场 | 元 |
| I | 回踩入场 | 元 |
| J | 竞价入场 | 元 |
| K | 不买区 | 元 |
| L | 硬止损 | 元（-7%） |
| M | 目标 1 | 元（+8%） |
| N | 目标 2 | 元（+15%） |
| O | 仓位% | 单只占总仓比例 |
| P | 持有期 | 周/日 |
| Q | **推荐逻辑** | 1-2 句话核心驱动力 |
| R | **关键催化** | 具体事件 + 时点 |
| S | **政策催化** | 对应文件/会议 |
| T | **行业地位** | 申万一/二级 + 是否主线 |
| U | **估值水位** | PE / PB vs 行业中位数 |
| V | **风险点** | 最大下行 + 黑天鹅 |
| W | **注意事项** | 进场条件 / 时间窗口 / 监控指标 |
| X | **消息面核查** | `clients.web_search` 关键结论摘要 |

**Q-X 列必须填实**，是 Excel 相对 Markdown 的核心增量。备注用 wrapText + 行高自适应。

### Sheet 2：候选

所有通过硬门槛但**未入选**的标的（含被二次剔除的）。

| 列 | 列名 | 说明 |
|---|---|---|
| A | 代码 | — |
| B | 名称 | — |
| C | 申万一级 | — |
| D | 评分 | — |
| E | 市值（亿） | — |
| F | 现价 | — |
| G | RSI6 | — |
| H | 乖离率MA5 | % |
| I | MA60 状态 | "上"/"下" |
| J | **剔除原因** | 哪条二次筛选规则被剔除 |
| K | **风险信号** | 超买/追高/MA60下/估值过高 等 |
| L | **重新关注条件** | 何时可重新纳入候选 |
| M | **观察池标记** | 是否进入观察池 / 跟踪 |

J-M 列是核心：必须说明"为什么没选 + 什么时候能回来"。

### Sheet 3：板块行业趋势

**板块涨幅榜** + **主线识别** + **资金切换** + **政策催化**。

| 列 | 列名 | 说明 |
|---|---|---|
| A | 申万一级 | 板块名 |
| B | 本周涨幅% | — |
| C | 排名 | 1-N |
| D | 主线状态 | ★★★★★ ~ ★ |
| E | 持续天数 | 主线已持续几个交易日 |
| F | 核心驱动 | 1 句话 |
| G | 政策催化 | 对应文件/会议 |
| H | 资金共识 | 北向/融资/ETF 至少 3 项 |
| I | 拥挤度 | RSI / 乖离率信号 |
| J | 下周展望 | 持有 / 减仓 / 切换 / 观望 |

顶部插入**总评段**：当前主线判断 + 资金切换路径 + 风控建议。

### Sheet 4：事件日历

下周关键事件（重点是下周内的事件 + 持仓股业绩）。

| 列 | 列名 | 说明 |
|---|---|---|
| A | 日期 | YYYY-MM-DD |
| B | 星期 | — |
| C | 事件 | — |
| D | 影响板块 | — |
| E | 对应持仓 | 代码 / 名称 |
| F | 应对动作 | 建仓 / 加仓 / 减仓 / 不动 / 砍仓 |
| G | 关键程度 | ★ 1-5 |

顶部插入**本周最关键事件 Top 3** 摘要。

## 格式规范

1. **首行冻结**：所有 sheet 第 1 行冻结
2. **列宽自适应**：A 列 8，备注列 50，其他按内容
3. **备注列**：wrapText=True，行高根据内容自动扩展
4. **关键数字格式**：
   - 价/止损/目标：`#,##0.00`
   - 涨跌幅/仓位：`0.00%` 或 `0.00`（百分点）
   - 市值/成交额：`#,##0.00`（亿）
5. **颜色编码**：
   - 精选 sheet：主策略列按 6 种策略上不同底色（突破=绿/回踩=蓝/涨停=红/事件=橙/反包=紫/主线=青）
   - 候选 sheet：剔除原因列按风险等级上色（超买=红/MA60下=橙/估值过高=灰）
   - 板块 sheet：主线评级 ★★★★★ 行底色金色
6. **汇总行**：精选 sheet 底部加 `合计` 行（仓位%、目标均价）

## 备注写法规范

每条备注必须**具体、可执行**，禁止"看好"、"强势"等空话。模板：

```
推荐逻辑：<具体驱动力，含数据点>
关键催化：<事件名 + 时点>
风险点：<具体下行场景，含数字>
注意事项：<进场条件 + 时间窗口 + 监控指标>
```

```python

                  meta={"base_date": "20261012", "风控总闸": "..."})
```

```python

build_workbook(
    output_path="/var/minis/shared/股票/短线选股/短线选股_20261012.xlsx",
    picks=[...],          # 精选 dict list（Q-X 列备注必填）
    candidates=[...],     # 候选 dict list（含剔除原因）
    sectors=[...],        # 板块 dict list
    events=[...],         # 事件日历 dict list
    meta={"base_date": ..., "风控总闸": ..., "板块总评": [...],
          "事件总评": ...},  # ⚠️ 板块总评是**行 list**，传字符串会被逐字符拆开
)
```

## 硬约束

1. **Q-X 列（精选）备注必填**，每条 ≥ 30 字
2. **J-M 列（候选）必填**剔除原因 + 重新关注条件
3. **板块 sheet 必填**主线判断 + 资金切换路径
4. **事件 sheet 必填**持仓对应关系
5. **文件名固定** `短线选股_YYYYMMDD.xlsx`（YYYYMMDD = 数据基准日）
6. **目录固定** `/var/minis/shared/股票/短线选股/`
