# 长中短线三层池指标（来自 fsi a-share-screen）

## 长线池（6-18 月）

**目的**：高股息 + 破净 + 核心资产底仓

| 指标 | 阈值 |
|---|---|
| 流通市值 | > 500 亿 |
| PB | < 1.0x（破净优先） |
| 股息率 | > 4.0%（TTM） |
| ROE | > 8%（连续 3 年） |
| 资产负债率 | < 70%（金融除外） |
| 所属行业 | 银行/煤炭/电力/公用/高速/铁路/保险/运营商 |
| 北向资金 | 近 60 日净流入 |
| 机构持仓 | 公募+社保+险资 > 30% |

## 中线池（3-6 月）

**目的**：产业周期向上 + 业绩验证 + 政策催化

| 指标 | 阈值 |
|---|---|
| 流通市值 | > 200 亿 |
| 行业景气度 | 上行周期 |
| 中报预增 | 净利润同比 > 50% 或 Q2 单季 > 30% |
| PE | 行业相对值 < 历史中位数 1.2x |
| MA60 | 现价 > MA60 且 MA60 向上 |
| 北向资金 | 近 20 日净流入 |
| 融资余额 | 近 20 日变化 > 0 |
| 催化窗口 | 90 日内有政策/中报/大会/订单 |

## 短线池（1-5 个交易日）

**目的**：中报预增王 + 事件驱动 + 高弹性

| 指标 | 阈值 |
|---|---|
| 中报预增 | 净利润同比 > 100%（优选 > 500%） |
| 量价异动 | 5 日均量 > 60 日均量 1.5x |
| 现价突破 | 突破 60 日均线 |
| 题材风口 | 当前市场主线 |
| 流通市值 | ≥ 50 亿（无上限，兼顾弹性与流动性） |
| 资金面 | 北向/融资 至少一项净流入 |
| 止损纪律 | 硬止损 **-7%**（全 skill 统一） |

## 配比与风控

**默认配比**：
- 长线 30% / 中线 40% / 短线 30% = 总仓位 5-6 成

**单股上限**（与各工作流纪律卡一致，不得各自另立口径）：
| 池 | 单票 | 持仓数 |
|---|---|---|
| 长线 | ≤ 5% | — |
| 中线 | 核心 ≤ 6% / 卫星 ≤ 4% | — |
| 短线（`short-screen`） | ≤ 10% | ≤ 3 只 |
| 打板（`limit-up`） | ≤ 5%（前 30 天 ≤ 2%） | ≤ 2 只，日总仓 ≤ 10% |

**止损**：
- 全 skill 统一 **-7% 硬止损**（短线选股 / 打板 / 中线 / 长线底仓跌破成本后的减仓触发线一致）
- 长线以基本面恶化为主要减仓依据，但价格跌破 -7% 仍先执行止损纪律，再看基本面决定是否回补
- 各工作流不得另立止损口径
