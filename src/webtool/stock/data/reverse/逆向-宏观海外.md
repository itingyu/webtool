### 2. 东方财富 datacenter-web 公共请求模板

固定参数（几乎所有函数都带）：

| 参数 | 固定值 | 说明 |
|---|---|---|
| `source` | `WEB` | |
| `client` | `WEB` | |
| `p` / `pageNo` / `pageNum` | `1` | 兼容三套分页字段名 |
| `sortColumns` | `REPORT_DATE` | 排序字段；准备金率用 `PUBLISH_DATE,TRADE_DATE`；房价用 `REPORT_DATE,CITY` |
| `sortTypes` | `-1` | 倒序；房价/准备金率用 `-1,-1` |

两种 reportName 家族：

- **A 类（`RPT_ECONOMY_*`）**：`columns` 显式列出字段，`pageSize` 一般 `500`/`1000`/`2000`，**单页返回，不翻页**（除 LPR 外）。
- **B 类（`RPT_ECONOMICVALUE_*`）**：`columns=ALL`，用 `filter=(INDICATOR_ID="EMG00xxxxx")` 定位指标，`pageSize=2000` 或 `5000`，**单页返回，不翻页**。
- **C 类（`RPT_INDUSTRY_INDEX`）**：`columns=REPORT_DATE,INDICATOR_VALUE,CHANGE_RATE,CHANGERATE_3M,CHANGERATE_6M,CHANGERATE_1Y,CHANGERATE_2Y,CHANGERATE_3Y`，`filter=(INDICATOR_ID="EMI/EMM00xxxx")`，**需要按 `data_json["result"]["pages"]` 翻页**（`_em_macro_1` 及所有 hyzs_list 系列）。
- **D 类（`RPTA_WEB_RATE`）**：LPR，`token=894050c76af8597a853f5b408b759f5d`，需翻页。

### 3. B 类（`RPT_ECONOMICVALUE_*`）列序映射

`columns=ALL` 时东财返回固定顺序的 9 个字段，源码按列序重命名（模式 A）：

| # | 原始字段（由 uk/germany/japan/swiss/hk 的 `rename` 反推） | 中文名 |
|---|---|---|
| 0 | `COUNTRY` | - |
| 1 | `INDICATOR_ID` | - |
| 2 | `INDICATOR_NAME` | - |
| 3 | `REPORT_DATE_CH` | **时间**（数据所属期） |
| 4 | `REPORT_DATE` | - |
| 5 | `PUBLISH_DATE` | **发布日期** |
| 6 | `VALUE` | **现值** |
| 7 | `PRE_VALUE` | **前值** |
| 8 | `INDICATOR_IDOLD` | - |

> 注意：加拿大（macro_canada.py）与美国（macro_usa.py）用的是**位置赋值** `temp_df.columns = ["-","-","-","-","时间","-","发布日期","现值","前值"]`（9 列，美国 PHS 与澳洲是 8 列 `["-","-","-","时间","-","发布日期","现值","前值"]`，即少了第 0 个 `-`）。**列数必须与源码一致，否则 `columns=` 赋值会抛 Length 不匹配**——这是这批接口最容易踩的坑。

输出列（所有 B 类统一）：`时间 / 前值 / 现值 / 发布日期`，按 `发布日期` 升序排序。

### 4. 金十 list_v2 公共请求模板

Headers（macro_china / macro_usa / macro_euro / macro_constitute）：

```python
{
  "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/107.0.0.0 Safari/537.36",
  "x-app-id": "rU6QIu7JHe2gOUeR",      # 固定 app id
  "x-csrf-token": "x-csrf-token",     # 固定占位值
  "x-version": "1.0.0",
}
```

macro_bank.py 的 headers 多 `Accept/Accept-Language/Origin/Referer`，且**没有** `x-csrf-token`。

参数：

| 参数 | 值 | 说明 |
|---|---|---|
| `category` | `ec`（经济指标） / `etf`（ETF 持仓） / `opec`（OPEC） | |
| `attr_id` | 指标数字 ID（见下表） | |
| `max_date` | `""` 起始，翻页时置为「本页最后日期 - 1 天」，格式 `YYYY-MM-DD` | |
| `_` | `str(int(round(time.time()*1000)))` 毫秒时间戳（反爬/防缓存） | |

**翻页机制（重要）**：没有 `page` 参数，而是死循环：请求 → 若 `data_json["data"]["values"]` 为空则 break → 取本页最后一行第 0 列日期 → `max_date = 该日期 - 1 天` → 重复。若服务端忽略 `max_date` 会**死循环**。

返回字段（列序映射，4 列）：

| # | 原始 | 中文名 | 含义 |
|---|---|---|---|
| 0 | `values[i][0]` | 日期 | 数据日期，字符串 `YYYY-MM-DD` |
| 1 | `values[i][1]` | 今值 | 当期公布值 |
| 2 | `values[i][2]` | 预测值 | 市场预期值 |
| 3 | `values[i][3]` | 前值 | 上期值 |

再加一列 `商品` = 函数传入的 symbol 字符串。最终列顺序：`商品 / 日期 / 今值 / 预测值 / 前值`，按日期升序。

`values` 内元素类型：数值列可能是数字或 `"--"`/`""` 字符串，源码统一 `pd.to_numeric(errors="coerce")`。

### 5. 金十 CDN `*.json` 公共形态

响应形如 `{"values": {...}, "keys": [{"name": "..."}, ...]}`。

- `values` 的 **key 是日期字符串**，value 是**列表**。
- `pd.DataFrame(json["values"]).T` → 行索引=日期，列=指标名，每格是 list。
- 两种拆包方式：
  - **2 元组**：`x[0]`=数值、`x[1]`=涨跌幅/变化量 → 生成 `{指标}-定价/-涨跌幅` 两列（Shibor/汇价）或 `{指标}-钻井数/-变化` 两列（贝克休斯）。
  - **3 元组**：`x[0..2]` 对应 `json["keys"][i]["name"]` → 生成 `{指标}-{key.name}` 三列（CFTC/LME）。源码用 `eval(str(x))[i]` 拆包。
- 空值填充：`temp_df.fillna(value="[0, 0, 0]")`（CFTC/LME）、`fillna(value="--")`（Shibor/汇价）。

### 6. 新浪财经宏观 `get_pagedata` 公共形态

- URL 中 `SINAREMOTECALLCALLBACK<13位时间戳>` **只是 JSONP 回调名，随便填**，源码里不同函数用了不同的固定串（1601557771972 / 1601559094538 / 1601624495046 / 1601651495761），不影响返回。
- 参数：`cate`（`industry` 行业 / `fininfo` 金融 / `price` 价格）、`event`（指标编号）、`from`（起始序号）、`num`（每页条数）、`condition`（筛选，空）。
- 返回是 JSONP 文本，源码用 `demjson.decode(data_text[data_text.find("{"):-3])` 截取（**尾部去掉 3 个字符**）。
- **列名完全由返回的 `config.all` 决定**：`big_df.columns = [item[1] for item in data_json["config"]["all"]]` → 所以字段名是**运行时动态**的，静态文档无法穷举（`（源码未明确）`，需实跑打印）。
- **需要翻页**：`page_num = ceil(count / 31)`，循环 `from = i*31`。
- 除 `macro_china_society_electricity` 用**硬编码 17 列名**外，其余全部用 `config.all` 动态取名。

### 7. 全局坑点清单

| 坑 | 说明 |
|---|---|
| **B 类列数不统一** | 美国 PHS 8 列、其余美加澳 9 列，列序赋值长度必须严格匹配 |
| **`columns=` 赋值依赖服务端字段顺序** | 东财 A 类接口一旦新增/调整字段顺序，映射全错；源码没有按名 rename 的地方必须核对 |
| **金十 list_v2 死循环风险** | `max_date` 若不生效会无限请求；源码没有重试上限 |
| **金十 `_` 时间戳** | 部分接口带 `?_={ms}` 防缓存，缺失可能返回旧缓存 |
| **`x-app-id` / `x-csrf-token`** | 金十必需，`x-csrf-token` 值是固定字符串 `"x-csrf-token"` |
| **NBS 需要预热会话** | `curl_cffi.requests.Session(impersonate="chrome")`，先 GET 页面再 POST，headers 需 `Origin`/`Referer` |
| **商务部接口 TLS** | 需自定义 `TLSAdapter`（SECLEVEL=1 + 强制 TLSv1.2），否则握手失败 |
| **同花顺/新浪是 HTML/GBK 表格解析** | 页面改版即失效；`currency_boc_sina` 响应为 GBK，`macro_china_freight_index` 需 `decode("gbk")` |
| **`macro_china_freight_index` 用 `pd.DataFrame.append`** | pandas ≥2.0 已移除该方法，源码在新版 pandas 上会报错（老代码遗留） |
| **`macro_china_fx_gold` 等缺 `columns` 别名** | 部分函数返回值字段与文档字段名大小写不一致，需实测 |
| **翻页** | 仅 C 类（RPT_INDUSTRY_INDEX）、`RPTA_WEB_RATE`（LPR）、新浪 `get_pagedata` 需要翻页；其余东财接口单页 |
| **drop_duplicates** | `_em_macro_1` 翻页后会 `big_df.drop_duplicates(inplace=True)` 再赋列名，顺序敏感 |

**dts 时间参数编码（`_build_nbs_dts`）**:

| 粒度 | 编码格式 | 示例 |
|---|---|---|
| year | `YYYYYY` | `2023YY` |
| month | `YYYYMMMM` | `202303MM` |
| quarter | `YYYY0QSS` | `202301SS`、`202304SS` |

输入 `period` 语法：
- `LAST<N>` → 取最近 N 个完整周期（`_get_last_completed_period` + `_shift_nbs_period`），如 `LAST10`
- `起始-结束` → `dts=["<start>-<end>"]`，如 `2016-2023`、`2016-`（结束留空 = 到最近完整周期）
- `2023`（仅年份，非 year 粒度）→ 自动展开为 `202301MM-202312MM`（month）或 `202301SS-202304SS`（quarter）
- 逗号分隔多值 → 多个 dts，如 `201801MM,201902MM`
- 季度也接受 `2023A/2023B/2023C/2023D` 字母格式，内部转 `01~04SS`

**指标名格式化**（`_format_nbs_indicator_name`）: 正则 `^(.*?)(累计值|当期值|本期值|期末值|平均值|同比增长率|同比增长|增长率|增速)(\([^)]*\))?$` → 转为 `{前缀}_{后缀}{单位}`，如 `国内生产总值_累计值(亿元)`。匹配时依次尝试 `i_showname` → `ek_dp_name` → `_name`。
