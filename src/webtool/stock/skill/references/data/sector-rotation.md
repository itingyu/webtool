# A 股板块轮动框架（来自 fsi china-sector-rotation 整合）

## 三大风格分组

| 风格 | 包含行业 | 适用情景 |
|---|---|---|
| **顺周期** | 银行 / 非银 / 房地产 / 煤炭 / 有色 / 钢铁 / 化工 / 建材 | 经济复苏 / 通胀上行 |
| **成长** | 电子 / 计算机 / 通信 / 传媒 / 电力设备 / 军工 | 流动性宽松 / 产业周期上行 |
| **防御** | 公用 / 农业 / 食品饮料 / 医药 / 交运 | 经济下行 / 风险偏好下降 |

## 经典轮动链

```
经济复苏早期：金融 → 周期（有色/煤炭/化工） → 消费
经济复苏中后期：消费 → 成长（医药/科技）
经济过热：周期 + 防御（公用/农业）
经济衰退：防御 → 金融（避险）
```

## 主线识别 4 标准

1. **政策催化**：有明确政策支持
2. **资金共识**：北向 + 融资 + ETF + 游资 至少 3 项共同流入
3. **行业涨幅**：当周 / 当月排名靠前
4. **持续性**：已持续 4 周以上，未见衰退

满足 3/4 = 主线。

## 调仓时机

| 信号 | 调仓动作 |
|---|---|
| 主线拥挤度 > 80% | 减仓主线 + 加仓防御 |
| 新政策窗口出现 | 试探性加仓新主线 |
| 风格切换确认 | 切换 50% 仓位 |
| 业绩验证落空 | 减仓预期落空标的 |
