# 东财 F10 财务报表接口逆向

> 源码: `stock_feature/stock_three_report_em.py`（约 2000 行，14 个函数）

## 关键前置：companyType 探测

东财 F10 新版接口必须带 `companyType` 参数，否则返回 1718 字节「无F10资料」占位符。
该值需先请求 HTML 页面，从隐藏 input 读取：

```python
GET https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/Index
params: type=web, code={symbol}.lower()
→ BeautifulSoup 解析 soup.find(id='hidctype')['value']
```
实测：SH600519 → companyType=`4`（通用）；金融类/其他类型为 3 等。

> 源码还用 `@lru_cache()` 缓存该值，避免重复请求。


## 接口一：取报告期列表

```
GET https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/zcfzbDateAjaxNew
```

| 参数 | 取值 | 说明 |
|---|---|---|
| `companyType` | 上一步探测值 | 公司类型，必填 |
| `reportDateType` | `"0"` 按报告期 / `"1"` 按年度 | |
| `code` | `"SH600519"` | 带市场前缀的代码 |

响应 `data[]` 每项：`SECURITY_CODE` / `REPORT_DATE` / `REPORT_TYPE` / `REPORT_DATE_NAME`

实测 SH600519 返回 103 期数据。


## 接口二：取三表数据

```
GET https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/{table}AjaxNew
```

`table` 取值：

| table | 报表 | 对应函数 |
|---|---|---|
| `zcfzb` | 资产负债表 | `stock_balance_sheet_by_report_em` |
| `lrb` | 利润表 | `stock_profit_sheet_by_report_em` |
| `xjll` | 现金流量表 | `stock_cash_flow_sheet_by_report_em` |

| 参数 | 取值 | 说明 |
|---|---|---|
| `companyType` | 探测值 | 必填 |
| `reportDateType` | `"0"` 报告期 / `"1"` 年度 / `"2"` 单季度 | |
| `reportType` | `"1"` 合并 / `"2"` 单季 / `"3"` 调整 / `"4"` 调整单季 | 按报告期接口需带 |
| `dates` | 逗号分隔的报告期 | **最多 5 个** |
| `code` | `"SH600519"` | |

### 批量调用模式（源码逻辑）

1. 先调 `zcfzbDateAjaxNew` 拿全部报告期
2. 按 5 个一组切片：`,`.join(dates[i:i+5])
3. 循环调 `{table}AjaxNew`，`pd.concat` 拼接
4. 若返回无 `data` 键则 `break`（源码防御性判断）

### 返回字段

实测 `zcfzbAjaxNew` 单条记录 **319 个字段**，全部为英文字段名。关键字段：

| 字段 | 含义 |
|---|---|
| `SECUCODE` | 带后缀代码 600519.SH |
| `SECURITY_CODE` | 6位代码 |
| `SECURITY_NAME_ABBR` | 简称 |
| `ORG_TYPE` | 报表类型(通用) |
| `REPORT_DATE` | 报告期 |
| `REPORT_TYPE` | 中报/年报/一季报 |
| `REPORT_DATE_NAME` | 2026中报 |
| `NOTICE_DATE` | 公告日 |
| `CURRENCY` | 币种 |
| `TOTAL_ASSETS` | 资产总计 |
| `TOTAL_LIABILITIES` | 负债合计 |
| `TOTAL_EQUITY` | 所有者权益 |
| `ACCEPT_DEPOSIT_INTERBACC` | 吸收存款 |
| `ACCOUNTS_PAYABLE` | 应付账款 |
| `CAPITAL_RESERVE` | 资本公积 |

> 完整 319 字段清单可用实测获得：调用该接口后 `list(data[0].keys())`。


## 降级逻辑

源码对 `by_yearly` 系列做了容错：首次请求失败时把 `companyType` 强制改为 `"3"` 重试。

```python
except:
    company_type = "3"
    params.update({"companyType": company_type})
    r = requests.get(url, params=params)
```

这解释了为什么自建客户端 `em_f10_*` 有时返回占位符——**没做 companyType 探测**。
