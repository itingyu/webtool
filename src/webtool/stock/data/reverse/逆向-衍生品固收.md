### 2. 通用日期格式

- **期货/期权**：多数接口用 `YYYYMMDD`（如 `trade_date="20250418"`），源码内部 `cons.convert_date()` 同时接受 `YYYY-MM-DD`/`YYYYMMDD`/`datetime.date`。
- **上交所**：日期参数拼接为 `YYYY-MM-DD`（`"-".join([d[:4], d[4:6], d[6:]])`）。
- **东财**：k线 `beg`/`end` 用 `YYYYMMDD`，`end=20500000` 表示至今。
- **中债/中国货币网**：`YYYYMMDD` 入参 → 请求转 `YYYY-MM-DD`。

### 4. 通用坑点

1. **模式A 列序映射**：东财绝大多数接口返回 `f1..fN`，akshare 用 `temp_df.columns = [...]` 按位置重命名——**第 N 个中文名 = 原始第 N 个字段**。本文所有此类表格均已按位置还原。
2. **翻页**：东财 `clist/get` 用 `fetch_paginated_data` 循环 `pn`；新浪 `Market_Center.getHQNodeData` 需先查 `getHQNodeStockCountSimple` 取总页数；天天基金 `funddataIndex_Interface.aspx` 需解析首包里的总页数。
3. **需要 Referer/Origin 的站点**：东财 `api.fund.eastmoney.com`、同花顺 `data.10jqka.com.cn`、`hq.sinajs.cn`、`query.sse.com.cn`、`www.szse.cn`、`www.chinamoney.com.cn`、`datacenter-api.jin10.com`（另需 `x-app-id`/`x-version`）。
4. **验签/加密**：新浪部分历史数据需 `py_mini_racer` 执行 `hk_js_decode` 解密；巨潮需动态 `Accept-Enckey`；集思录需 `___jsl` 时间戳；乐咕需 `get_token_lg()`。
5. **证书**：郑商/国泰君安/99期货多处 `verify=False`。
6. **反爬 IP 封禁**：新浪沪深债券/可转债实时接口源码注释明确"大量抓取容易封 IP"。
7. **非交易日**：几乎所有"按日期取行情"的接口都先用本地交易日历（`get_calendar()`，JSON 至 2019 年底，**需按年更新**）判断，非交易日直接返回空 DataFrame 或 `None`。

### 5.2 特殊要求 / 坑点清单（按严重度）

1. **`futures_trading_hours_em`**（futures/futures_rule_em.py:28）**函数体只有 `pass`，是空实现**，调用返回 `None`。
2. **大商所/郑商所/上期所「按交易日」接口都要本地交易日历前置校验**：`option/cons.py` 的 `get_calendar()` JSON **仅覆盖到 2019 年底**（源码 docstring 明确"需要按年更新"）。传入非交易日会 warning 并返回空 DataFrame/None。
3. **郑商所仓单日报格式切换**：`futures_warehouse_receipt_czce` 中 `int(date) > 20251101` 用 `.xlsx`，否则 `.xls`（xls 需 `xlrd`）。
4. **郑商所期权历史文件有品种上市年份门槛**：`option_hist_yearly_czce` 内置 `symbol_year_dict`，早于上市年直接返回空表。
5. **上期所仓单日报有两条路径**：`date >= "20140519"` 走 `.dat` JSON（并对 `VARNAME/REGNAME/WHABBRNAME` 按 `$` 截断），更早走 `.html` 表格切分。
6. **新浪 CF（郑商）节点自 20220601 字段变动**，`futures_zh_spot` 用 `try/except` 分叉两套列序。
7. **新浪外盘 `hq.sinajs.cn` 伦敦金（XAU）返回 15 列，其余 14 列**；源码用 `if len(data_df.columns)==14` 插入占位列再统一命名。
8. **`hq.sinajs.cn` 必须带 Referer**，否则返回空串。
9. **`fund_rating_sh` 用 `raise "字符串"`**（Python 3 非法），日期不匹配时会以 TypeError 形式抛出，不是友好报错。
10. **`fund_scale_daily_szse` 日期跨度超过 6 个月静默返回空表**（带表头），`_parse_date` 强制 `len==8 and isdigit()`。
11. **深交所 ETF/期权 xlsx**：`pd.read_excel` 需 `openpyxl`；`dtype={"基金代码": str}` 防前导零丢失；`option_current_day_szse` 需 suppress "Workbook contains no default style" 警告。
12. **上交所 ETF 份额单位是"万份"**，`fund_etf_scale_sse` 里 `* 10000` 才等于份数。
13. **`futures_rule`（国泰君安）用 `verify=False`**（自签证书）。
14. **`fund_lcx_rank_em` 源码自述"该接口暂时没有数据"**。
15. **持仓排名的口径差异**：上期所/中金所只公布"品种内标的排名"，akshare 输出的品种排名是各标的加总，**不是真实品种排名**；大商所恰好相反（只公布品种排名）。这是最容易误用的点。
16. **新浪沪深可转债实时接口源码注释明确"大量抓取容易封IP"**。
17. **集思录 `___jsl` 参数**必须为毫秒级时间戳，否则返回参数错误。
18. **巨潮 `Accept-Enckey` 必须动态生成**（本地 `cninfo.js` 的 `getResCode1()`）。
19. **新浪部分历史数据需要 JS 解密**：`py_mini_racer` 执行 `hk_js_decode`（可转债/ETF 历史）。
20. **广期所接口全部要求 `Origin`/`Referer`/`X-Requested-With`**（`gfex_headers`）。
21. **列序映射（模式A）无法从运行时验证**，字段数一旦变化会静默错位或报长度不匹配；文中所有 `temp_df.columns = [...]` 表格应作为契约固定。
22. **`futures_zh_cov_info` 的 `quoteColumns`** 用东财内部 `f<n>~<单位>~<字段>~<小数位>` 语法拼装，字段含义需对照东财字段 ID。
23. **深交所 `random` 参数**：多个接口带随机小数参数（`ShowReport`），照抄源码值即可，通常用于破缓存。
24. **中债接口 POST 但参数放在 query string**（`requests.post(url, params=params)`），非常反直觉。
25. **`fund_etf_hist_em` 的 market_id 推断**：先试 1 失败再试 0，且最终无数据时返回空 DataFrame——个别 ETF 可能静默为空。
