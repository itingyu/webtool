# 集合竞价 4 形态（来自 fsi cn-morning-note）

## 时间窗口
- 9:15-9:20 可挂单可撤单（虚拟撮合）
- 9:20-9:25 只可挂单不可撤单
- 9:25 产生开盘价
- 9:30 开盘连续竞价

## 4 种典型形态

| 形态 | 含义 | 操作 |
|---|---|---|
| 9:15 高开 → 9:20 涨停 | 主力坚决做多 | 排队买龙头 |
| 9:15 高开 → 9:25 回落 | 开盘预期落空 | 观望 / 等二次启动 |
| 9:15 低开 → 9:20 跌停 | 恐慌出货 | 观察板块 |
| 9:15 低开 → 9:25 反弹 | 主力吸筹 | 关注是否站稳 |

## 核心信号

- 集合竞价涨停股所属板块 = 当日最强风口
- 集合竞价跌停股所属板块 = 当日最大风险
- 集合竞价成交量是昨日同期 2x+ = 资金异动
- 9:25 后看涨跌幅排序：+5% 以上个股数量判断情绪强度
