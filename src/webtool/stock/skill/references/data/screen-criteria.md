## C. 组合层检查（`short_pool.run()` 自动算出，只提示不剔除）

| 检查 | 阈值 | 工具字段 |
|---|---|---|
| 60 日位置分位 | > 0.9 标 `高位`，0.3-0.9 标 `中位`，< 0.3 标 `低位` | `position_60d` / `position_tag` |
| 行业分散度 | 通过数 ≥ 3 时，申万一级应 ≥ 3 个 | `industry_dispersion` / `industries` |
| 高位股清单 | 逐个复核 60 日涨幅是否已透支 | `high_position_codes` |

工具只把问题列进 `portfolio_notes`，**不自动删票** —— 集中或分散是策略选择，
由 agent 结合当期行情决定取舍。但 **notes 非空时必须在报告里写明处理结论**，
不能默默丢掉。

> `position_60d` = (现价 − 近 60 日最低) ÷ (近 60 日最高 − 近 60 日最低)，
> `position_window` 给出实际参与计算的天数（新股不足 60 日时按实际算）。

## 评分系统（0-100）

| 模块 | 满分 | 关键判定 |
|---|---|---|
| 均线多头排列 | 20 | MA5/10/20/60 + MA20↑ |
| 量能 | 20 | 量比≥1.5 涨 / 0.8-1.2 温和 / <0.5 缩量无分 |
| MACD | 20 | 金叉 + HIST > 0 + HIST 扩大 |
| RSI (6) | 20 | 50-70 健康 / >80 超买 / <30 超卖 |
| 乖离率 MA5 | 20 | ±5% 合理 / >10% 追高 / <-10% 超跌 |

### 信号库（不扣分但标记）

- RSI > 80 → `超买-不买`
- 乖离率 MA5 > 10% → `追高-不买`
- 量比 < 0.5 + 现价 > MA20 → `缩量滞涨-减仓`
- 北向连续 3 日净流出 → `资金撤离`

## 换手率阈值分阶段（易错点）

换手率随交易时段累积，**同一阈值不能同时用于盘中与盘后**：

| 阶段 | 换手区间（参考） | 说明 |
|---|---|---|
| 盘中（< 2h） | 0.5% - 5% | 按时间折算，不能用盘后阈值 |
| 盘后（全天） | 2% - 25% | 过低无流动性，过高筹码不稳 |

`short_tool.py check` 的换手软项**仅作提示，不达标不必然删除**。
