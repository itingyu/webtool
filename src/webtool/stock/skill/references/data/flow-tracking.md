# A 股资金面跟踪（来自 fsi china-flow-tracker 整合）

## 五大资金面分层

| 资金类型 | 重要性 | 数据频率 | 接入方式 |
|---|---|---|---|
| **北向资金**（沪深港通） | ★★★★★ | 实时 / 日终 | 雪球 + 东财（部分被 ban） |
| **融资融券** | ★★★★ | 日终 | 沪深交易所披露 |
| **ETF 申赎** | ★★★★ | 日终 | 基金公司公告 |
| **龙虎榜** | ★★★ | 次交易日披露 | 沪深交易所 |
| **南向资金** | ★★★ | 实时 / 日终 | 港交所披露 |

> **沙盒限制**：东财数据中心部分接口被 ban；龙虎榜走巨潮兜底；ETF 申赎需要专门接口（暂未对接）

## 北向资金信号

| 信号 | 含义 |
|---|---|
| 单日净买入 > 100 亿 | 外资显著加仓，多为趋势转折 |
| 单日净卖出 > 100 亿 | 外资明显减仓，警惕回调 |
| 连续 5 日净流入 | 中期趋势确认 |
| 行业切换：电子→银行 | 风格切换 |
| 个股切换：茅台→宁王 | 偏好切换 |
| 北向 + 融资 双流入 | 强反弹信号 |
| 北向流出 + 融资增加 | 杠杆接盘外资筹码，警惕诱多 |
| 北向流入 + 融资下降 | 外资低位吸筹，散户割肉 |

## 融资信号

| 信号 | 含义 |
|---|---|
| 融资余额突破 2 万亿 | 历史高位，警惕回调 |
| 融资余额连续 5 日下降 | 杠杆资金撤离 |
| 个股融资余额激增 50%+ | 短线博弈，注意回踩 |
| 融资余额 / 流通市值 > 10% | 个股杠杆过高风险 |

## ETF 信号

| 信号 | 含义 |
|---|---|
| 宽基 ETF 大幅净申购 | 机构 + 散户抄底 |
| 行业 ETF 净申购 | 板块行情启动 |
| 跨境 ETF 净赎回 | 资金回流 A 股 |

## 龙虎榜信号

| 信号 | 含义 |
|---|---|
| 涨停 + 机构净买入 > 5000 万 | 中线资金介入 |
| 涨停 + 顶级游资净买入 | 短线题材发酵 |
| 跌停 + 机构净卖出 > 5000 万 | 基本面恶化 |
| 涨停 + 量化席位主导 | 警惕次日回调 |
| 连续 3 日登龙虎榜 | 短线博弈白热化 |

## 主力资金（大单/小单）

| 指标 | 含义 |
|---|---|
| 大单（> 100 万） | 主力资金 |
| 中单（20-100 万） | 中型投资者 |
| 小单（< 20 万） | 散户 |

| 信号 | 含义 |
|---|---|
| 大单持续净流入 + 股价涨 | 主力推动上涨，可信 |
| 大单持续净流出 + 股价涨 | 散户接盘，警惕见顶 |
| 大单净流入 + 股价横盘 | 主力吸筹 |
| 大单净流出 + 股价横盘 | 主力派发 |
