# Merger Model — 并购模型

**触发词**：merger / M&A / 并购 / accretion dilution

## Workflow

### Step 1: 交易结构
- 现金 / 股票 / 混合
- 对价 / 溢价
- 换股比例

### Step 2: 合并财务
- 合并收入 / 成本
- 协同效应（成本协同 / 收入协同）
- 整合成本

### Step 3: 融资
- 现金来源
- 债务 / 股票发行
- 利息影响

### Step 4: Accretion / Dilution
- 收购方 EPS 影响
- Pro forma EPS
- Break-even 时间

### Step 5: 敏感性

| 协同 / 溢价 | 10% | 20% | 30% |
|---|---|---|---|

## 输出形态

并购模型 + Accretion/Dilution 表格。

> **说明**：本工作流不依赖特定数据源，由用户/agent 提供交易细节。
