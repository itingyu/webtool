## 同花顺 10jqka.com.cn

| 端点 | 用途 | 反爬要求 |
|---|---|---|
| `http://data.10jqka.com.cn/market/longhu/` | 龙虎榜 | 需 hexin-v cookie |
| `http://data.10jqka.com.cn/funds/{hyzjl|ggzjl}/` | 资金流向 | 同上 |
| `http://data.10jqka.com.cn/ipo/{xgsgyzq|xgfxq}/` | 新股 | 同上 |
| `http://data.10jqka.com.cn/macro/finance/` | 宏观 | 同上 |
| `https://basic.10jqka.com.cn/basicapi/finance/index/v1/app_data/` | 财务 JSON API | 需 Referer |
| `https://q.10jqka.com.cn/thshy/` | 行业板块 | IP 级封禁风险 |

**hexin-v cookie**：akshare 用 `py_mini_racer` 执行 `hexin_v.js` 生成 60 字符 token。

> 实测结论（本沙盒）：主域 `q.10jqka.com.cn` 被 nginx 403，但 `data.` / `stock.` / `news.` / `futures.` / `stockpage.` 子域**不受影响**，且是 SSR 可直接 GET，比算 token 更高效。

## 巨潮资讯 cninfo.com.cn

| 端点 | 方法 | 用途 |
|---|---|---|
| `https://webapi.cninfo.com.cn/api/sysapi/p_sysapi1007` | POST | 公告查询（`column=szse`） |
| `https://www.cninfo.com.cn/new/hisAnnouncement/query` | POST | 历史公告 |

**POST 参数**：`stock`（`600519,gssh0600519` 格式）、`tabName`（`fulltext`/`relation`）、`pageSize`、`pageNum`、`column`（`szse`/`sse`）、`category`、`seDate`（`2020-01-01~2023-08-19`）

**必需**：先 GET `https://www.cninfo.com.cn/new/index` 拿 `JSESSIONID` cookie；`Content-Type: application/x-www-form-urlencoded`；带 `Referer: https://www.cninfo.com.cn/`

## 腾讯财经

| 端点 | 用途 | 格式要求 |
|---|---|---|
| `https://qt.gtimg.cn/q={codes}` | 多市场报价 | 逗号分隔；**A 股 `sh600519`、港股 `hk00700`、美股 `usTSLA`（不带点）、B 股 `sh900901`** |
| `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get` | K线 | `param=hk00700,day,,,320,qfq` |
| `https://web.ifzq.gtimg.cn/appstock/app/minute/query` | 分时 | `code=sh600519` |

> 不支持：`us.AAPL`（带点）、`b_sh900901`、`fund_`、`fx_`。
