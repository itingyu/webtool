## 政策事件分类（4 维度）

| 维度 | 选项 |
|---|---|
| **方向** | 利好 / 利空 / 中性 |
| **力度** | 重大（★★★★★）/ 重要（★★★）/ 一般（★） |
| **时效** | 短期（<1周）/ 中期（1-3月）/ 长期（>3月） |
| **板块映射** | 直接受益 / 间接受益 / 中性 / 利空 |

## 政策解读框架

```
[政策名称] — [方向] [力度]

1. 核心要点：原文关键 2-3 句
2. 增量信号：相比上次的新增 / 删除 / 措辞变化
3. 板块映射：直接/间接受益
4. 时滞判断：短期 / 中期 / 长期
5. 历史回测：近 3 次类似政策后 A 股表现
```

## 央行政策工具

| 工具 | 影响 |
|---|---|
| 降准（-25/-50bp） | 释放流动性，银行间利率下行 |
| 降息（OMO/MLF/LPR） | 实体融资成本下行 |
| 结构性工具（PSL/再贷款） | 定向支持 |
| 买断式逆回购 | 投放长期流动性 |
