# A 股特殊规则

| 规则 | 影响 | 操作 |
|---|---|---|
| **T+1** | 当日买入次日才能卖 | 短线必须设硬止损 |
| **涨跌停** | 主板 ±10% / 创科 ±20% / ST ±5% / 北证 ±30% | 涨停战法注意差异 |
| **停牌** | 重大事项可能停牌数日 | 流动性风险 |
| **分红除权** | 高息股除权日跳空 | 正常现象 |
| **新股市值申购** | 需持有沪深市值 | 才有新股额度 |
| **北交所 30 万门槛** | 北证 50 标的散户受限 | 风险偏好要求 |
| **融资融券门槛** | 50 万 + 6 个月交易经验 | 杠杆资金 |
| **盘中撮合** | 9:30-11:30 / 13:00-14:57 连续竞价 | 9:15-9:25 集合竞价 |
| **收盘价确定** | 14:57-15:00 收盘集合竞价 | 尾盘博弈 |
| **交易单位** | 100 股 = 1 手 | 买入需为整手 |
| **印花税** | 卖出收 0.05% | 短线交易摩擦 |
| **佣金** | 通常万 2.5（含规费） | 找客户经理可调 |
