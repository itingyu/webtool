# Short-Screen — 短线选股（1-5 日持有，稳健模式）

**触发词**：短线选股 / 每日候选 / 盘中可买入清单 / 涨停过滤 / 复盘 / 下周一买什么 / 入场价位

> ⚠️ **本工作流是「稳健」模式，与 `limit-up`（进攻）冲突。
> 同一时段只跑一个，不要混用输出。**

---

## 0. 三条死原则

1. **涨停/一字板直接删** —— 买不到就不算机会，不写"不建议"。
2. **传统行业 > 题材故事** —— 房地产/白酒/煤炭/汽零等确定性高于题材。
3. **先复盘再开新仓** —— 上一交易日炸板/天地板/严重缩量 → 自动降级观察。

## 2. 阶段判断

| 当前时间 | 阶段 | 必做 |
|---------|------|------|
| 08:30-09:25 | 盘前 | 出候选清单，**9:25 集合竞价后必须二次验证** |
| 09:30-11:30 | 盘中 | 实时严格过滤，聚焦开盘 30 分钟表现 |
| 11:30-12:30 | 午休 | 午前复盘 + 下午/次日预案 |
| 12:30-15:00 | 午盘 | 实时过滤，聚焦换手与主力净流入持续性 |
| 15:00-15:30 | 盘后 | 完整复盘 + 次日预案 |
| 周末/节假日 | 非交易日 | 输出**沿用预案 + 下一交易日预案**，禁止编造"今日盘面" |

---

**持仓周期：1-5 个交易日（T+1 短线）**。超过 5 个交易日仍无正收益 → 按纪律出局，
不转中线、不摊薄。

## 3. 硬过滤（一票否决）

### 3.1 不可买板块（第 0 关，最优先）

| 代码前缀 | 板块 | 本 skill | 开通门槛（仅作说明） |
|---|---|---|---|
| 600/601/603/605 | 沪市主板 | ✅ 唯一参与 | — |
| 000/001/002/003 | 深市主板 | ✅ 唯一参与 | — |
| 300/301 | 创业板 | ❌ 一律排除 | 24 个月 + 10 万 |
| 688 | 科创板 | ❌ 一律排除 | 24 个月 + 50 万 |
| 8 / 920 / 430 | 北交所 | ❌ 一律排除 | 24 个月 + 50 万 |
| 900 / 200 | 沪深 B 股 | ❌ 一律排除 | 需开通 B 股 |
| ST / *ST / 退市整理 | 风险警示 | ❌ 一律排除 | 50 万 + 24 个月 |

**口径**：本 skill 只做**沪深主板**。上表后 5 行的"门槛"列只是说明市场规则，
**不代表有权限就能参与** —— 工具层 `unbuyable_reason()` 硬过滤，无例外、无人工绕过。

`filter` / `pool --only-buy` 自动执行，**不通过直接删，不"勉强"**。

### 3.2 风险股（基本面 / 事件，`screening.risk_check` 自动执行）

`risk_check.scan(code)` 一次跑完以下三类，命中即剔除：

**A. 重组股**（近 90 日公告）
- 重大资产重组 / 借壳 / 控制权变更 / 要约收购 / 发行股份购买资产 / 资产置换

**B. 事件类**（近 30 日公告）
- 减持 / 立案 / 调查 / 警示函 / 监管函 / 问询函 / 业绩预亏 / 商誉减值 / 计提减值 / 退市风险

**C. 基本面红线**（雪球财务指标最新一期）
- 质押率 > 60%
- 资产负债率 > 80% **且** 净利润同比 < 0

拉不到财务数据时写入 `pending` 并在输出中标注，**不得当作已通过**。

其余硬门槛：
- 流通市值 ≥ 50 亿（无上限）
- 20 日均成交额 ≥ 1 亿

## 4. 可买入性三档（`check` 输出）

| 结论 | 含义 | 动作 |
|---|---|---|
| ✅ 可追（温和区 5-9.5%） | 硬闸全过（已封板/一字板则直接删） | 进候选，给三档入场价 |
| ⚠️ 降观察 | 硬闸过但软项不达标 | 进候选但标注不达标项，仓位减半 |
| ❌ 删除 | 权限 / 已封板 / 空间不足 | 进「已删除清单」，写明原因 |

> **换手阈值分阶段**：盘中现价换手天然偏低，不能用盘后阈值砍盘中票。
> `check` 的软项提示仅作参考，**不达标不必然删除**。

## 5. 评分（100 分制）

**两套口径，不可混用：**

| 口径 | 函数 | 构成 | 用在哪 |
|---|---|---|---|
| 技术面分（0-100） | `ti.score_short(df)` | 均线 20 + 量能 20 + MACD 20 + RSI 20 + 乖离 20 | **短线池硬门槛 ≥ 60**（`short_pool` 用它） |
| 综合分（0-100） | `ti.score_general(df, news_items, macro_score)` | 技术面 60（= 技术分×0.6）+ 消息面 30 + 宏观 10 | 单股深度 / 研报 / 输出卡片展示 |

| 模块 | 满分（技术面口径） | 关键判定 |
|---|---|---|
| 均线多头 | 20 | MA5/10/20/60 全上 + MA20↑ + MA60↑ |
| 量能 | 20 | 量比 ≥1.5 且价涨 / 1.2 温和 / <0.5 缩量无分 |
| MACD | 20 | 金叉 + HIST>0 + HIST 扩大 |
| RSI(6) | 20 | 50-70 健康 / >80 超买 / <30 超卖 |
| 乖离率 MA5 | 20 | ±5% 合理 / >10% 追高 / <-10% 超跌 |

**门槛：技术面分 ≥ 60 / 100**。信号库（标记但不扣分）：
RSI>80 → `超买-不买`；乖离率>10% → `追高-不买`；
量比<0.5 且价>MA20 → `缩量滞涨-减仓`；北向连续 3 日净流出 → `资金撤离`。

> 消息面 30 分需传 `news_items`（`clients.news(code)` 的标题列表）才有区分度，
> 不传则按中性 15/30 计 —— 单股深度输出里要写清是哪种。

详细计算见 `../data/screen-criteria.md`。

## 7. 输出

### 7.1 Markdown

```sh
python3 scripts/short_tool.py header --mode pre --kind screener
```

表头由 `header` 生成。正文按 `../templates/short-screen-card.md`：

1. 单只卡片（推荐逻辑 / 关键催化 / 估值水位 / 风险点 + 三档入场价 + 交易策略）
2. 末尾 4 件汇总：组合一览表 / 板块轮动 / 事件日历 / 风控总闸
3. **已删除清单**（必含，写明触发原因）

### 7.2 Excel（强制，4 sheet）

| Sheet | 内容 |
|---|---|
| 精选 | 入选标的 + 每只详细备注（推荐逻辑/催化/风险/注意事项） |
| 候选 | 过硬门槛但未入选 + 剔除原因 + 何时可重新关注 |
| 板块行业趋势 | 本周板块涨幅 Top/Bottom、主线识别、资金切换路径 |
| 事件日历 | 下周关键事件 + 对应持仓 + 应对动作 |

**尺寸自适应**：本策略生成 6-8 只精选（长线 10-12 / 中线 8-10）。

## 8. 入场 / 出场

三档入场（`technical_levels` 输出具体数字，禁止"前高附近"这类模糊表述）：

| 类型 | 触发条件 |
|---|---|
| 突破 | 放量突破阻力位 × 1.005 + 量比 ≥ 1.5 |
| 回踩 | 缩量回踩 MA10/MA20 不破 |
| 竞价 | 9:25 集合竞价走强但高开 < 5%（高开 > 5% 不追） |

> **与打板的差异（刻意不同，不可互相污染）**：短选走稳健路线，
> 高开 > 5% 一律不市价追，等回踩；打板走进攻路线，5-9.5% 可直接挂单。
> 两个工作流**互斥**，跑哪个就守哪个的口径。

出场：

- 硬止损 **-7%**（必须给具体价格）
- 目标 1 +8% / 目标 2 +15%
- 组合单日回撤 > 3% → 总仓降 1 成；单周回撤 > 5% → 暂停加仓
